Using PyVAM Web

PyVAM Web is an interactive, browser-based viewer for annotated animal mitochondrial genomes. It uses PyVAM's Python rendering functions through Pyodide to produce circular maps, coordinate-scaled linear maps, and non-proportional gene-order diagrams. It does not infer phylogenetic trees or mitochondrial rearrangement events.

1. Quick start

  1. Open PyVAM Web and wait until the runtime status reports the renderer is ready. The first visit may take longer while Python packages download.
  2. Click Load example dataset to load the 18 accession IDs listed below, automatically choose Gene order and the TAN colour theme, and begin retrieving GenBank records from NCBI. Alternatively, select your own GenBank files or paste NCBI nucleotide accession IDs.
  3. Wait for the download and rendering status. Each selected accession has a separate status; failed accessions may be retried individually. Loading 18 records can take time because requests are processed sequentially.
  4. Switch between Circular, Linear, and Gene order, change colours and labels, and select Rotate / align at to choose a shared gene anchor.
  5. Use Download PyVAM SVG, Download PNG (300 dpi) or Download PDF to save the current figure.

2. Example: comparative gene-order view

The built-in demonstration requests the following 18 NCBI nucleotide accessions, in the supplied order. The button fills the accession text field, selects the Gene order view and TAN colour scheme, and starts retrieval and rendering automatically.

MK804158, MK804156, MK804154, MK804151, MK804150, MK804153, MK804152, MK804164, MK784108, MK804148, MK804159, MK804149, MK804157, MK804155, MK804160, MK804163, MK804162, MK804161

Inspect example records at NCBI Nucleotide. The example requires internet access to NCBI; PyVAM does not bundle the GenBank files. These identifiers are provided as demonstration inputs and are not independently reannotated or validated by PyVAM.

How to interpret the result: compare gene labels, strand directions and their relative order between records. A visually different arrangement is an annotation-based observation, not proof of a particular duplication, loss, transposition or evolutionary history. Confirm candidate differences against the original records and independent annotations where relevant.

3. Input formats and data preparation

  • Local GenBank files: choose one or more annotated files with .gb, .gbk, .genbank or .txt extensions. Records must contain recognizable genomic features; raw FASTA sequence is not a substitute for annotation.
  • NCBI accessions: paste a list separated by newlines, commas, semicolons or spaces and click Add NCBI accessions. NCBI E-utilities supplies GenBank text when requests succeed.
  • Species labels: choose Use filename as species name to display file-derived names rather than record-derived names. Add accession ID appends accession identifiers where supported.
  • Missing or inconsistent features: plots reflect available annotations; PyVAM is not a de novo mitochondrial genome annotator. Review suspicious gene labels, absent genes and fragment boundaries.

4. Views and biological interpretation

ViewPurposeLimitations
CircularVisualize annotated features on individual mitochondrial genome circles, with optional GC-content ring.The reference start position is chosen for presentation; apparent differences can reflect alternative GenBank origins.
LinearCompare annotated genes along a genome-length coordinate axis; useful for relative span and location.Genome length and coordinate conventions matter; incomplete or linear genomes should not be assumed circular.
Gene orderDisplay gene arrangement schematically without proportional gene lengths; useful for comparing relative order across genomes.Not an inferred ancestral gene order or event reconstruction. Repeated labels indicate annotations that should be checked for true gene duplications.

5. Figure settings

Colour scheme selects a built-in PyVAM palette such as TAN; Gene Class Colors optionally overrides colours for classes of genes. Rotate / align at specifies the visual reference gene when supported. Gene labels, font sizes, legend placement, and species-name options change presentation, not annotations.

Remove D-loop / NCR suppresses the control/noncoding region in the display. Force reorientation for linear genomes changes presentation of linear records and should be used only if its interpretation is appropriate. For circular plots, controls include label placement, drawing direction and GC-ring parameters. For linear maps, options include axis visibility and inter-row spacing. Gene-order diagrams have a separate box-height control.

6. Export and reproducibility

Exports reflect the last successfully rendered view. SVG and PDF are vector-oriented outputs from Matplotlib; PNG is rendered at 300 dpi. Record your input accession numbers or GenBank files, PyVAM version, selected view, colour scheme and relevant display options when preparing publication figures.

7. Troubleshooting

ProblemWhat to try
Runtime stays on “Preparing PyVAM…” or failsCheck network access to the Pyodide CDN, reload and use an up-to-date desktop Chrome or Firefox browser.
NCBI record fails to downloadVerify the accession at NCBI, retry the failed item, or download its GenBank file manually and upload it. NCBI may limit request rates or network access.
A figure does not renderCheck that each file is valid annotated GenBank, remove the problematic record and retry with fewer inputs. Inspect on-page errors.
Large batches take too longTry a smaller selection and keep the browser tab open while Pyodide renders. The current page runs Python computations within the browser.
Unexpected gene-order differencesInspect original gene names, strand annotations, duplicated features and record completeness; alignment of drawing origins is not rearrangement inference.
Wrong species namesToggle Use filename as species name or review the ORGANISM and accession annotations.

8. Privacy, availability and citation

Locally selected files are written to Pyodide's in-memory filesystem and are not intentionally uploaded to a PyVAM server. Retrieving NCBI accessions sends requests to NCBI, and first-time runtime initialization downloads packages from a CDN. The application does not require an account.

PyVAM source code is publicly available under the MIT License. For versions, documentation, reproducibility and issue reporting, see the PyVAM GitHub repository. Cite the software release and its associated publication when available.
